If a single reviewer comment contains multiple independent concerns, use subrows (for example, R1.1a and R1.1b) while preserving the original comment identifier and wording. Close the parent only after its actionable subconcerns are resolved.

When multiple reviewers raise the same concern, cross-reference the shared evidence or manuscript change while retaining a direct answer under each original comment.

For each evidence entry, include the source artifact or analysis identifier needed to verify it independently of the response summary.

Reopen a previously closed concern if a later edit removes or contradicts the evidence or manuscript passage supporting its closure.

## Status vocabulary

- **Open** — concern not yet answered.
- **Partial** — the answer needs stronger evidence, a necessary manuscript revision, or a verifiable location.
- **Closed** — the direct answer and sufficient evidence agree with the cited manuscript text. Record any necessary revision or cite the existing text if it already answers the concern.
- **Not actionable** — positive/descriptive comment, no response needed.
