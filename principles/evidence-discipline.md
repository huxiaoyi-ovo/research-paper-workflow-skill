# Evidence and Provenance Discipline

## Five epistemic levels
1. Confirmed fact
2. Supported evidence
3. Reasonable inference
4. Working hypothesis
5. Author judgment

Do not write levels 3–5 as level 1.

## Revision provenance classes

| Class | Meaning |
|---|---|
| Original evidence, clarified | Already existed in v1; revision improves description |
| New revision experiment | Newly run because of review |
| New baseline / analysis | New comparison or post-hoc analysis |
| Corrected factual description | Old wording/geometry/count/name was wrong |
| New interpretation | Same result, better or narrower interpretation |
| Presentation-only | Figure, terminology, layout, readability |

Use verbs that match history: clarify, add, extend, correct, reinterpret, replace.

## Claim-evidence matching

For each important claim, write:

> Claim → evidence → scope → unresolved alternative.

If the evidence only supports tested conditions, say tested conditions.
