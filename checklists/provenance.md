# Provenance Checklist

For every major result or revision claim:

- [ ] Already in original submission?
- [ ] Genuinely new revision work?
- [ ] Presentation-only change?
- [ ] New interpretation?
- [ ] Corrected factual description?
- [ ] Old or newly generated numbers?
- [ ] Response-letter verb historically correct?
- [ ] Could reviewer mistakenly think data were rerun/replaced?
- [ ] Does unchanged data make sense given the stated revision?
- [ ] Are train / validation / test roles explicit?

Audit every occurrence of: “we added”, “we repeated”, “we reran”, “we introduced”, “we removed overlap”, “new held-out”, “new test environment”, “we corrected”.
