# Reviewer Closure Checklist

For each actionable reviewer comment:

- [ ] Correct reviewer/comment ID
- [ ] Correct original order
- [ ] Faithful original wording
- [ ] Reviewer-supplied citations and references checked against the actual sources before accepting their characterization
- [ ] Underlying concern identified
- [ ] Original-manuscript state verified
- [ ] Revision-new vs original evidence classified
- [ ] Direct answer appears early
- [ ] Strongest evidence included
- [ ] Any claimed changes are present in the manuscript
- [ ] Section, figure, table, and page or line references match the final submitted version
- [ ] The cited location addresses the concern, including when the text already did so
- [ ] Claim no stronger than evidence
- [ ] No unnecessary weakness introduced
- [ ] No new factual/provenance question created
- [ ] Related comments answered consistently
- [ ] Final status: closed / partial / open / not actionable

Use the status definitions in the [response matrix](../templates/reviewer-response-matrix.md). Do not mark an actionable concern as not actionable merely because the requested experiment is unnecessary; explain the alternative evidence or scope decision instead.

If decisive evidence is unavailable, record the missing source and retain an open or partial status rather than inferring closure.

A major concern is closed when a skeptical reviewer can find the answer, evidence, and supporting manuscript passage without inferring a missing link.
