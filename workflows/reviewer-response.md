# Reviewer Response Workflow

## Step 1 — reconstruct the review exactly
Preserve original order, wording, categories, and supplied references.

If positive/descriptive comments are omitted, explain why numbering may be non-consecutive.

## Step 2 — build the response matrix

| Field | Question |
|---|---|
| ID | What is the original identifier? |
| Surface request | What did the reviewer literally ask? |
| Underlying concern | What decision concern is behind it? |
| Original manuscript | What did v1 actually say/do? |
| Evidence available | What evidence already exists? |
| Action type | Clarify / edit / analyze / experiment / narrow scope |
| New work? | Is this revision-new? |
| Manuscript change | What exactly changes? |
| Response claim | What can we safely say? |
| New-question risk | Could this answer create another concern? |
| Closure status | Open / partial / closed |

## Step 3 — answer in the right order
1. direct answer;
2. strongest evidence;
3. manuscript change;
4. location.

## Step 4 — calibrate tone
Do not over-defend. If evidence is sufficient, state it and stop.

## Step 5 — verify against manuscript
Every “we revised / added / clarified” statement must be true in the final manuscript.
